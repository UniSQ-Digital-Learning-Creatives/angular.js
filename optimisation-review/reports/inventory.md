## 1. Method, scope and limitations

**Corpus per page** = the HTML; every `<script src>` that is local or shared (resolved through the HAProxy path map: `/utilities.js`->si-manager/public, `/ilar-toolbox|/editor-popups|/studydesk-toolbox/*`->toolbox/public, `/images/*`->toolbox/public/images); inline `<script>`; `<script type="text/ng-template">` bodies; every `templateUrl`/`ng-include`/`$.get('sys/pages/...')` target (resolved to a file by exact tail match, or, for dynamic names like `'sys/pages/' + page + '.html'`, every file under the literal prefix directory); HTML inside JS string/template literals. Third-party `node_modules` libs and `vendor/` bundles are listed, not parsed.

**Extraction:** JS parsed with @babel/parser (0 parse errors on 787 file-instances) -> DI params, call sites (`.$watch(a,b,true)` etc.), DDO objects, `$`-token usage, `angular.*` references, provider config calls. Markup via a quote-aware HTML tokenizer (comments stripped) -> attribute names normalised (`data-`/`x-`/`ng:`/`ng_`), tags, input types, anchors, forms, `{{}}` and `ng-*` expressions -> an expression lexer finds filters, `::`, `$index`..., and Angular's own regexes parse `ng-repeat` and `ng-options`.

**"Unused" verification** (section 13): each claim is backed by (a) the tokenised/AST scan, (b) a **raw case-insensitive grep including comments** over the same files and over a 993-file wide net of every html/js/svg in the 24 app dirs (catching unlinked/dynamic files), (c) a ui-grid source+template scan, (d) a dynamic-name search for string-built `ng-` names. Evidence counts are in `inventory.json` (`unused[].evidence`).

**Known blind spots:** runtime-fetched HTML that is `$compile`d (only `sys/pages/*.html` in this repo, all resolved); strings built at runtime from DB content; global CSS outside the repo (Moodle themes) - cannot reach these iframes; any production CSP header. 2 pages are dead (counted but flagged).

1. **`element` argument of link functions** (96 link fns): `[0]` raw DOM access dominates; jqLite-compatible calls: `on/off/bind/attr/addClass/removeClass/text/html/empty/append/parent/find(tag)`. **jQuery-only calls on the `element` param:** `select2()` (podcast-manager select2, si-admin select2, 3d-model-viewer select2, toolbox select2), `.offset()` (si-photography-catalogue tooltip, inline-completion-tracker tooltip (+`.width()`), reaction-bar tooltip -> 3 pages index/modal/injector), `.position()`/`.width()` + `.find('.stars-filled .star')` selector-find (si-manager/toolbox-feedback `stars`), `.offset()`/`.width()` (toolbox-podcast-player `progressBar`), `.closest('svg')` (generators profile-image-generator `image`), and **selector `find`** (jqLite `find` only supports tag names): `find('.inc-button')`/`find('.dec-button')` in generators counter-button-editor `incDecButtons` + introduction-text/tables `ilarNumberInput` (x3 `find('input')` is fine), `find('.play-button')`/`find('.stop-button')` in toolbox-pronunciation-guide `player` (main.js:353); `find('div')` (tag, ok) in banner-generator. **Total: 14 directive definitions affecting 17 pages** (select2 x4, tooltip x3 -> reaction-bar 3 pages, stars, progressBar, image, incDecButtons (index + embed.html - on the jqLite embed page the class-selector find already returns nothing), ilarNumberInput x2, player). Smallest app fix: wrap the link `element` as `$(element)` (or `angular.element`->`$`) at those 14 sites.

2. **jQuery-normalised event objects**: link-fn `element.on(...)` handlers that read `e.originalEvent` unguarded (would throw under jqLite, which passes the native event) - **banner-generator main.js:355 (contenteditable keydown), profile-image-generator main.js:632 (image mousedown), toolbox-podcast-player main.js:510 and :771 (progressBar/volume touchstart|mousedown), toolbox-photospheres main.js:1162 (viewer mousemove)**. The other `.originalEvent` readers sit on the app's own `$(window)/$(document).on(...)` (profile-image-generator:643, podcast-player:528/715/783, photospheres:985, reaction-bar main.js:246-301 `storage`) and are unaffected by what angular.element is. Guarded `(e.originalEvent || e)` forms (rive-player-editor, gift-quiz-converter, banner-generator:400) are safe. `$event` in `ng-click` templates is a jQuery.Event today; templates only use `stopPropagation/preventDefault/currentTarget/key/target.*` (all native-compatible).

3. **`$destroy` element events / `jQuery.cleanData` patch**: `element.on('$destroy', ...)` used by horizontal-rule `change`, profile-image-generator `image`+`change` (3 sites) - works in jqLite too (jqLite fires `$destroy` on `remove()/dealoc`), but elements removed by app-side jQuery (`$el.remove()`, `.html()`, `.empty()`) while Angular owns them only trigger `$destroy` via the jQuery cleanData patch.

4. **`angular.element(...)` in app code:** only course-development-reports main.js:843-844 (`angular.element(html)`, `angular.element(document.body).prepend(...)`: both jqLite-safe). `$document.on/off` (media-catalogue clickToggle): jqLite-safe. `.scope()/.isolateScope()/.injector()/.inheritedData()`: 0 callers. `$compile(...)(scope)`: 13 call sites on 8 pages - the result is used only as `[0]` (raw node) or ignored.

## 17. Surprises / things the lead should know

1. **Two pages are dead** (main.js absent): `si-analytics` and `toolbox-course-roadmap` - they cost nothing at runtime but any change "affecting all 46 pages" really affects 44.
2. **App code touches almost no Angular API surface** (see 0): no `$http/$q/$rootScope/$location/$interval/$injector/$templateCache`, only `$sce/$parse/$compile/$filter/$timeout/$document`. The surface that matters is *directive/template* behaviour (ng-if x416, ng-click x401, ng-class x293, ng-show x258, ng-repeat x144, ng-model x191, ng-include x177 - distinct sites) plus `$applyAsync` (407 sites).
3. **ui-grid is the only consumer of** `$http`, `$q`, `$rootScope`, `$interval`, `$injector`, `$provide.decorator`, `ng-transclude`, `replace:true`, directive `priority`, `compile`, multi-name directives, `$emit/$broadcast`, `$new`, `$observe`, `attrs.$$observers`, `$$hashKey` reads and `angular.version.major/minor` - all confined to ONE page (course-development-reports). Making these optional (or demanding an app-side opt-in) affects a single app.
4. **`$http` is always instantiated** (via $compile->$templateRequest) although no app calls it; **`$location` is instantiated on the 25 ng-include pages purely as a side effect** (ngInclude eagerly injects $anchorScroll) although no app uses `autoscroll` or `$location`. Both are free wins if made lazy.
5. **Form-state CSS classes** (`ng-valid/-invalid/-dirty/-pristine/-touched/-untouched/-pending/-submitted`) and debug classes are referenced by **no** CSS/JS/HTML in the suite; only `ng-not-empty` (si-photography-catalogue) is consumed. 43 of 46 pages already disable debug info.
6. **`ilar*` transclusion is wasted work:** 12 directive definitions set `transclude:true` but their templates never use `ng-transclude`.
7. **`track by`-less ng-repeat (80 sites)** make Angular write `$$hashKey` onto app data; apps compensate with `angular.toJson` clones (13 pages) - and ui-grid depends on `$$hashKey` being present. Any ng-repeat identity change must keep `$$hashKey` for ui-grid rows and keep `toJson` stripping.
8. **`ng-if` on `<style>` x25 (8 pages)**, `ng-model` on non-form elements (ilar-* custom elements, contenteditable/monaco/volume/fetch-json divs), and `<ilar-*>` + `transclude:true` + `templateUrl` + `ng-model` combined: unusual compile paths worth keeping covered by tests.
9. **Event/prefix shadowing:** app directives named `ngLoad`, `ngError`, `ngScroll`, `ngNoteImage`, `ngTemplatePreview`, `change`, `scope`, `image`, `audio`, `icon`, `player`, `chart`, `percentage`, `tooltip`, `tippy`, `select2`... A directive named `change`/`scope`/`image`/`audio`/`icon`/`player` also matches ANY element/attribute with that name in those apps' templates.
10. **CSP:** no `ng-csp`, no CSP header in the current prod haproxy config; the only CSP (without unsafe-eval) is in a legacy nginx example config. If a CSP were applied, Angular would silently switch to the slower AST interpreter - confirm none is set.
11. **jQuery-only calls on link `element`** exist in 14 directive definitions on 17 pages (section 15), so "drop jQuery support" is not free for those apps.
12. Brief's numbers re-measured (distinct sites, shared files de-duplicated): ng-repeat 144 (brief 142), ng-model 191 (195), ng-bind-html 33, ng-model-options 12 (11), `$applyAsync` 407 (395), deep `$watch` 56 (58), class directives 13, `ng-include` 177 incl. 222 SVG files resolved, `window.parent.m` JS files 17 (brief 17; 23 files incl. html `$` hits).
